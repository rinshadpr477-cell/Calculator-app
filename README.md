#  Calculator App

A simple and responsive calculator application built using HTML, CSS, and JavaScript. The application performs basic arithmetic operations through an intuitive user interface.

##  Live Demo

🔗 https://calculator-app-sigma-six-71.vercel.app/

##  Features

* Addition
* Subtraction
* Multiplication
* Division
* Clear Display
* Responsive Design
* User-Friendly Interface
* Real-Time Calculations

##  Tech Stack

* HTML5
* CSS3
* JavaScript (ES6)
